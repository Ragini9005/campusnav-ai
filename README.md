# CampusNav AI 🎓

## AI-Powered Campus Navigation System

CampusNav AI is a smart campus navigation assistant designed to help students quickly find buildings, laboratories, offices, libraries, and other campus facilities.

## ✨ Features

- 🧭 Campus navigation
- 🔎 Smart facility search
- 🤖 AI campus assistant
- 🎤 Voice navigation
- 📏 Distance estimation
- ⏱️ Walking time estimation
- 🗺️ Interactive campus map
- 🔄 Clear navigation

## 🎯 Problem Solved

New students often struggle to find classrooms, laboratories, offices, libraries, and other facilities on large campuses.

CampusNav AI provides a simple and user-friendly way to find a destination and understand how to reach it.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Web Speech API
